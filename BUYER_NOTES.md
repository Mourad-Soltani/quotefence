# Buyer notes — QuoteFence
Author: Mourad.Soltani

## Who pays

Independent designers, developers, and 2–10 person studios who send quotes from email or Notion. They already feel scope creep. They do not want another full PSA / legal suite.

## Pain in one line

Vague briefs become unpaid work because the quote never named exclusions, a validity window, or a change-order rule.

## Wedge

A paste-box that returns Markdown they can drop into email the same hour. No model bill. Deterministic flags they can explain to a client.

## Differentiation vs nearby GitHub work

- Not a physical fencing estimator
- Not a 9-agent local RFP pipeline
- Not a Word-doc interview agent
- Small enough to white-label or embed in a studio handbook

## Pricing tests

1. $19/mo, 200 fences, CSV export later
2. $29 studio seat
3. Lifetime $149 for indie hackers (use only as a launch spike)

## Next 14 days if a buyer funds it

- Simple HTML paste UI
- API key + Stripe Checkout
- Saved quote history
- PDF export
- Industry packs (web, brand, video)

## Risks

- Legal-looking output is still a template, not counsel
- Phrase list will need weekly additions from real briefs
- Do not commit GitHub tokens or customer briefs to git
